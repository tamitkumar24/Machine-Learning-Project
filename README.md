# Heart Disease Prediction App ❤️🩺

A Machine Learning web application built with Python and Streamlit that predicts the likelihood of heart disease using a K-Nearest Neighbors (KNN) classifier. 

## Live Demo
**Test the live application here:** [Heart Disease Predictor](https://tamitkumar24-machine-learning-project-app-nekuyi.streamlit.app/)

##  Project Structure
* `app.py`: The main Streamlit application script containing the frontend UI and backend logic.
* `KNN_heart.pkl`: The trained K-Nearest Neighbors machine learning model.
* `scaler.pkl`: The data scaler used to normalize user inputs to match the training data.
* `columns.pkl`: The saved feature columns ensuring the input format matches the model's expectations.
* `requirements.txt`: The list of Python dependencies required to run the application.

## Technologies Used
* **Python**
* **Streamlit** (Web Framework)
* **scikit-learn** (Machine Learning)
* **Pandas** (Data Manipulation)
* **Joblib** (Model Serialization)

## How to Run Locally

If you want to run this project on your own machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/tamitkumar24/Machine-Learning-Project.git](https://github.com/tamitkumar24/Machine-Learning-Project.git)
   cd Machine-Learning-Project


Install the required dependencies:
Make sure you have Python installed, then run:

Bash
pip install -r requirements.txt

Run the Streamlit app:

Bash
streamlit run app.py
The app will automatically open in your default web browser.
